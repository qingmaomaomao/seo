# Page Modules Content Specification

Detailed content requirements for each module of a Create landing page.

---

## Module 1: Hero Title & Subtitle

### Title Formulas

Use these proven H1 patterns, inserting the primary keyword:

| Pattern | Example |
|---------|---------|
| `[Keyword] - [Outcome] in [Timeframe]` | AI Game Maker - Create Games in Minutes |
| `[Keyword]: [Value Prop]` | AI Game Maker: No-Code Game Creation |
| `Free [Keyword] - [Benefit]` | Free AI Game Maker - Build Games Without Coding |
| `[Keyword] for [Audience]` | AI Game Maker for Beginners |
| `The Best [Keyword] - [Differentiator]` | The Best AI Game Maker - Powered by AI |

### Subtitle Guidelines

The subtitle expands on the H1 with:
- A secondary keyword (naturally embedded)
- The core value proposition
- What makes SEELE AI different

**Formula:** `[How it works] + [Key benefit] + [Differentiator]`

**Examples:**
```
H1: AI Game Maker - Create Games in Minutes
Subtitle: Describe your game idea in plain text and watch SEELE AI build it for you. No coding required, no game engine experience needed.

H1: AI Website Builder - Design Sites with AI
Subtitle: Turn your vision into a fully functional website. SEELE AI generates responsive, production-ready code from your description.
```

### Meta Tags

**Meta Title (≤60 chars):**
`[Primary Keyword] - [Short Value Prop] | SEELE AI`

**Meta Description (≤160 chars):**
`[Action verb] + [primary keyword benefit] + [secondary keyword] + [CTA]. [Differentiator].`

**Example:**
```
Title: AI Game Maker - Create Games in Minutes | SEELE AI
Description: Build your own games with AI Game Maker. Describe your idea, generate playable games instantly. No coding needed. Try SEELE AI free today.
```

## Module 3: Quick Start Options

### Purpose

Quick Start cards serve two goals:
1. **SEO**: Capture long-tail keyword traffic by targeting specific sub-queries
2. **Conversion**: Give users immediate, specific entry points to start using the product

### Content Structure

Each card:
```
Title: [Action] + [Specific Thing] (include long-tail keyword)
Description: One sentence explaining what they'll create/achieve
CTA: Action verb ("Start Creating", "Try Now", "Build This")
```

### Patterns by Keyword Category

**For "AI Game Maker" intent:**
```
- Create a Platformer Game → Classic jump-and-run gameplay with enemies and power-ups
- Make an RPG Adventure → Story-driven game with characters and quests
- Build a Puzzle Game → Brain-teasing mechanics and progressive difficulty
- Design a Racing Game → Fast-paced tracks with vehicles and obstacles
- Create a Shooter Game → Action-packed gameplay with targets and scores
- Make a Card Game → Strategic card mechanics with AI opponents
```

**For "AI Website Builder" intent:**
```
- Create a Portfolio Site → Showcase your work with a professional layout
- Build a Landing Page → High-converting page for your product or service
- Design a Blog → Content-focused site with clean typography
- Make an E-commerce Store → Product listings with cart functionality
- Create a Business Site → Professional presence with contact forms
- Build a SaaS Dashboard → Admin interface with data visualizations
```

**For "AI Code Generator" intent:**
```
- Generate a React Component → UI components with props and state
- Create an API Endpoint → REST or GraphQL with proper error handling
- Build a Database Schema → Structured data models with relationships
- Generate Utility Functions → Reusable helpers for common tasks
- Create a Form Handler → Input validation and submission logic
- Build Authentication Flow → Login, signup, and session management
```

### Long-tail Keyword Embedding

Each Quick Start title should target a searchable phrase:
- Bad: "Platformer" (too generic)
- Good: "Create a Platformer Game" (matches "how to create a platformer game")
- Good: "Make an RPG Adventure" (matches "make rpg game with ai")

## Module 4: Core Features

### Feature Framing Strategy

Features should be framed from the **user's perspective for this specific intent**, not as generic product capabilities.

**Reframing by intent:**

| SEELE AI Capability | AI Game Maker Framing | Website Builder Framing | Code Generator Framing |
|---------------------|----------------------|------------------------|------------------------|
| Text-to-output generation | Describe your game, AI builds it | Describe your site, AI designs it | Describe functionality, AI codes it |
| No coding required | Make games without programming | Build sites without developers | Generate code without writing it |
| Instant preview | Play your game immediately | See your site in real-time | Test your code instantly |
| Full customization | Tweak every game element | Customize every design detail | Modify generated code freely |
| Export options | Download or share your game | Deploy to any hosting | Export clean, documented code |

### Feature Content Template

```
Title: [Benefit-focused, include keyword variation]
Description: [What it does] + [Why it matters] + [Outcome for user]
CTA: [Action that leads to experiencing this feature]
```

**Example for "AI Game Maker":**
```
Title: AI-Powered Game Generation
Description: Simply describe your game idea in plain English. SEELE AI understands your vision and generates playable game code, complete with graphics, mechanics, and interactions. What once took months now takes minutes.
CTA: Start Creating

Title: No Coding Required
Description: You don't need to learn Unity, Unreal, or any game engine. SEELE AI handles all the technical complexity. If you can describe what you want, you can make a game.
CTA: Try It Free

Title: Instant Play Testing
Description: See your game come to life in seconds. Every change you make is immediately playable in the preview. Iterate rapidly until your game feels just right.
CTA: See It in Action
```

### Image Requirements

For each feature, provide guidance for image generation:
- What the image should show (UI screenshot, abstract illustration, user scenario)
- Style direction (modern, playful, professional, technical)
- Key elements to include

## Module 7: FAQ

### Question Patterns

Use question formats that match actual search queries:

| Pattern | Example |
|---------|---------|
| What is [keyword]? | What is an AI game maker? |
| How do I [action] with [keyword]? | How do I make a game with AI? |
| Can [keyword] do [specific thing]? | Can AI game maker create 3D games? |
| Is [keyword] free? | Is AI game maker free to use? |
| [Keyword] vs [alternative]? | AI game maker vs Unity? |
| Do I need [skill] to use [keyword]? | Do I need coding to use AI game maker? |
| How long does [keyword] take to [outcome]? | How long does it take to make a game with AI? |

### Answer Structure for Featured Snippets

First sentence: Direct answer (this is what Google extracts)
Following sentences: Context, details, SEELE AI specifics

**Example:**
```
Q: How do I make a game with AI?
A: To make a game with AI, describe your game idea in plain text and let an AI game maker like SEELE AI generate the code for you. You don't need any programming experience. Simply write what kind of game you want — characters, mechanics, style — and the AI builds a playable version in minutes. You can then customize, test, and export your game.
```

### FAQ Topic Coverage

Ensure FAQs cover these categories:
1. **What it is** — Definition and basic explanation
2. **How it works** — Process and workflow
3. **Requirements** — Skills, cost, prerequisites
4. **Capabilities** — What can and can't be done
5. **Comparison** — How it compares to alternatives
6. **Getting started** — First steps
