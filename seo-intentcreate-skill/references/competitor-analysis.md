# Competitor Analysis Guide

## Analyzing Competitor Landing Pages

When competitor URLs are provided, extract these elements:

### Information to Extract

1. **Positioning**: How do they describe their product? What value prop leads?
2. **Keyword usage**: Which keywords appear in H1, H2s, and meta tags?
3. **Page structure**: What sections do they include? In what order?
4. **Feature claims**: What capabilities do they highlight?
5. **Weaknesses**: What do they NOT mention that SEELE AI can do?
6. **Pricing model**: Free tier? Trial? Paid only?
7. **CTA strategy**: What actions do they push users toward?

### Extraction Priority

Focus on elements that directly inform our comparison section (Module 5):
- Feature claims → comparison dimensions
- Weaknesses → SEELE AI advantages
- Pricing → value positioning

## Building the Comparison Table

### Comparison Dimensions

Select 5-8 dimensions from this prioritized list, choosing those most relevant to the keyword intent:

| Dimension | What to Compare | SEELE AI Advantage |
|-----------|----------------|-------------------|
| AI Generation | Text-to-output capability | Describe and generate — no manual building |
| Speed | Time to first result | Minutes vs hours/days |
| No-Code | Technical requirement | Zero coding knowledge needed |
| Output Quality | Polish of generated result | Production-ready output |
| Customization | Post-generation editing | Full control after generation |
| Export Options | Output formats | Web, mobile, embed, download |
| Price | Cost to use | Free tier available |
| Multi-format | Range of outputs | Games, websites, interactive content |

### Comparison Positioning Rules

1. **Be factual** — Only claim advantages that are genuinely true
2. **Use specific language** — "Generate in 2 minutes" beats "Fast"
3. **Reframe weaknesses** — If a competitor has a feature SEELE AI lacks, either omit that dimension or reframe it (e.g., they have "100+ templates" → we have "AI-generated custom designs, no templates needed")
4. **Keyword-aligned dimensions** — For "AI Game Maker" intent, prioritize game-related comparison points; for "Website Builder" intent, prioritize web-related points

### Comparison Table Structure

```
| Feature | SEELE AI | Competitor A | Competitor B |
|---------|----------|-------------|-------------|
| [Dim 1] | ✓ [specific detail] | ✗ / Limited | ✗ / Partial |
| [Dim 2] | ✓ [specific detail] | ✓ [their version] | ✗ |
```

### Section Copy Guidelines

**Title**: "[Primary Keyword]: SEELE AI vs Others" or "Why SEELE AI for [keyword intent]"

**Subtitle**: 1-2 sentences framing the comparison, embedding a secondary keyword.

**Below-table CTA**: Reinforce SEELE AI's strongest advantage with a conversion-focused call to action.

## Competitor Research Workflow

1. Read competitor page content from provided URLs
2. Extract positioning, features, and weaknesses
3. Map competitor claims to comparison dimensions
4. Identify 2-3 clear SEELE AI advantages
5. Select 5-8 comparison dimensions that highlight these advantages
6. Write factual, specific comparison copy
